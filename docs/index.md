# ovos-busmon docs

`ovos-busmon` shows every message on the OVOS messagebus as a dense,
DevTools-style log in a web page. You can watch the log, filter it with chips
and click-to-filter, mute high-frequency noise, inspect a row, trace one
interaction, inject a message, chat with the assistant, and export a capture.

Read the pages in this order:

1. [Tutorials](tutorials.md): step-by-step tasks for a first-time user.
2. [Usage](usage.md): a reference for each part of the UI and the HTTP API.
3. [Troubleshooting](troubleshooting.md): symptoms, causes, and fixes for
   common problems.

For installation and the two transport modes, see the [README](../README.md).
