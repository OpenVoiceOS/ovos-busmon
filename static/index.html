About ovos-busmon

A live monitor for the OpenVoiceOS message bus — watch, filter, trace, and inject bus messages in real time to see what your assistant is doing.

Developed by TigreGotico for OpenVoiceOS.

Built with substantial help from an AI coding assistant. It has automated tests and is reviewed before release; review the source before production use.
